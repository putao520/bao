Options:
  -e, --eval <EVAL>
          Evaluate the given code string (Bun-style top-level `-e`/`--eval`). When present, Bao runs the code and exits â no subcommand needed. Equivalent to `<BIN> run --eval <code>`
      --timeout <TIMEOUT>
          Terminate a runaway script after <MS> milliseconds (engine-native interrupt; exit code 124, GNU-timeout convention). While a controlled script entry is in flight, SIGINT (Ctrl-C) cancels it gracefully (exit code 130) instead of killing the process. Applies only to script execution (`<BIN> run`, `bao -e`); without it nothing changes
      --webdriver [<PORT>]
          Serve the WebDriver protocol on [PORT] (default 7000) and run until the WebDriver Shutdown command. Upstream `--webdriver[=port]`
      --hard-fail
          Exit non-zero if the engine hits a hard error (upstream `--hard-fail`; accepted for command-line parity â bao fails hard by default)
      --ignore-certificate-errors
          Skip peer-certificate verification failures (upstream `--ignore-certificate-errors`; wptrunner always passes it)
      --enable-experimental-web-platform-features
          Enable experimental web platform features (upstream `--enable-experimental-web-platform-features`)
      --window-size <WxH>
          Initial viewport as WxH (upstream `--window-size`)
      --certificate-path <PATH>
          CA certificate to trust for page TLS (upstream `--certificate-path`)
      --prefs-file <PATH>
          JSON file of preferences applied onto the global pref store (upstream `--prefs-file`; wptrunner passes resources/wpt-prefs.json)
      --pref <K=V>
          Single preference override K=V (upstream `--pref`, repeatable)
      --user-stylesheet <PATH>
          User stylesheet injected into every page (upstream `--user-stylesheet`, repeatable)
      --config-dir <DIR>
          Per-profile config directory (upstream `--config-dir`)
      --temporary-storage
          Use throwaway storage for this run (upstream `--temporary-storage`; accepted for command-line parity â bao already keeps per-run state)
      --headless
          Headless mode (upstream `--headless`; bao is headless by default â accepted for command-line parity)
      --expose-internals
          Expose internal modules to `require()` (node parity `--expose-internals`). Accepted so node-convention subprocess vehicles start. Honest boundary: bao has no `internal/*` module namespace â `require('internal/...')` still fails MODULE_NOT_FOUND; this flag only unlocks the vehicle, it does not fake internals
      --permission
          Enable the permission model (node parity `--permission`). Installs the process-level `CliPermissionModel` whose only observer is the `process.permission.has` face (node v24 parity; REQ-ENG-007). Honest boundary: bao wires no child-process/wasi/... grant flags, so those scopes report no grants; fs enforcement itself (fs.* call denial) is not wired â the model is the observable allow list
      --allow-fs-read <PATH>
          Grant fs read access to PATH under the permission model (node parity `--allow-fs-read=<PATH>`, repeatable). Requires `--permission` (node ERR_MISSING_OPTION parity); `*` grants everything
  -v, --version
          Print the version and exit 0 (node/bun parity face: `node -v` / `bun -v` print the bare version string â no name prefix, no extra text)
