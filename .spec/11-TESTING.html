§8 Mock 策略

  • Node API 模块（fs/path/crypto/http）：直接调用，无需 Mock

BUG-ENG-354: Bun.serve server.stop() SIGSEGV — 64-bit pointer truncated to Int32Value

server_stop() stores app_ptr as Int32Value (4 bytes) but on 64-bit systems pointers are 8 bytes. When stop() reads back the truncated pointer via JS_GetProperty and casts to *mut App<false>, the upper 32 bits are lost → invalid pointer → SIGSEGV. Location: src/bao_runtime/src/bun_api.rs:1228 (store) and :1238-1242 (read+cast). Fix: Use JS::ObjectValue with a typed object, or store the pointer as two i32 values, or use a PrivateValue slot instead of Int32Value.

BUG-SEC-001: install_all_native() Node API global leak — require/fs/crypto 挂在 Window global

runtime_bridge.rs 中 install_all_native() 将 require/fs/crypto/Bun.* 等 Node.js API 直接挂在 Window global 上，导致页面 JS 可通过 typeof require === 'function' 访问 Node API，违反 REQ-SEC-003 沙箱隔离要求。根因：原始实现未区分 Page Realm 和 Node Realm，所有 API 写入同一个 global。修复：CommonJS 参数注入 — install_all_native() 重构为 create_node_api_scope_values()，Node API 只安装到 Node Realm global。

BUG-SEC-002: Node Realm use-after-free — 页面关闭后指针悬空

页面关闭时 Node Realm 的 JSObject 指针未正确清理，后续 evaluate_js 调用访问已释放内存导致 SIGSEGV。根因：PageInner::close() 未调用 remove_node_realm() 清理 NODE_REALMS HashMap 中的映射。修复：close() 中增加 remove_node_realm(pg) 调用 + node_realm_global 置 null。

BUG-SEC-003: Cross-thread Node REALMS HashMap — 无 Mutex 保护的并发访问

NODE_REALMS HashMap 被多个线程并发访问（servo script thread 写入 + main thread 读取）但缺少同步机制，导致 HashMap 内部状态损坏和随机 panic。修复：改用 std::sync::Mutex<HashMap<usize, usize>> 保护所有读写操作。

BUG-SEC-004: Navigation DOM proxy stale — 导航后跨 Realm proxy 失效

页面导航后 servo 替换了 Window/Document/Navigator 对象，但 Node Realm 中缓存的跨 Compartment proxy 仍指向旧对象，导致 use-after-free。修复：增加 dom_proxies_dirty flag + register_refresh_dom_proxies 机制，evaluate_js 调用时检测并刷新 proxy。

BUG-SEC-005: evaluate_js IIFE fallback broken — Node API 懒初始化缺陷

PageHandle::new() 创建页面时不调用 inject_node_apis_with_stealth，node_realm_global 保持 null。evaluate_js 的 IIFE fallback 从 page scope 读取 require（已被 SEC-003 清除），导致所有 Node API 始终为 undefined。修复：移除 broken IIFE，改为 PageHandle::evaluate_js 棒初始化 — 捕获 null node_global 信号后触发 inject_node_apis_with_stealth 创建 Node Realm。

BUG-CDP-001: CDP server deadlocks ×2 — lock ordering + recursive lock

bao_cdp server 中两个独立的 deadlock：1) Session 创建时的 lock ordering 不一致 2) Domain command dispatch 中的 recursive lock。修复：统一 lock ordering + 分离 command dispatch lock 和 session lock。

BUG-CDP-002: CDP bridge race conditions ×6 — command routing channel 竞争

CDP command routing 中多个 race condition：1) Runtime.evaluate bridge race 2) 6个 command route 中的 channel 竞争 3) Emulation bridge race。根因：BridgeChannel 的 send/recv 无内存序保证。修复：增加消息序列化层 + channel flush barrier。

BUG-ENG-001: GC-related segfaults — global-property storage rooting 错误

global-property storage 方式中 SpiderMonkey GC root 管理不当，导致多个 SIGSEGV 崩溃。根因：JS::Rooted<JSObject*> 栈上对象在函数返回后成为悬垂指针，后续 GC 访问野指针。修复：改用 JS::PersistentRootedObject 或将 global property 存储在不会移动的堆位置。

BUG-ENG-002: Buffer.isBuffer returns false — _isBuffer type mismatch
