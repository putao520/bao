02-USERSTORY — 用户故事

PRD-USERSTORY-WEBDEV Web 开发者:一套工具链替代 Node 全家桶

作为 Web 开发者，我想要 不安装 Node.js 与包管理器,用 bao 一条工具链完成跑脚本、跑测试、打包、装依赖,现有 Bun/Node 程序原样迁移，以便 本机少一套运行时依赖,零学习成本切换,团队项目无缝搬迁

覆盖需求:PRD-REQ-SCRIPT-RUN、PRD-REQ-TOOLCHAIN、PRD-REQ-BUN-COMPAT、PRD-REQ-NODE-COMPAT、PRD-REQ-BUILTIN-DATA(蓝图 US-1)。

PRD-USERSTORY-FULLSTACK 全栈工程师:同进程起服务与无头渲染

作为 全栈工程师，我想要 同一段服务端代码里既起 HTTP 服务,又对页面做无头渲染出截图，以便 前后端联调与 SSR 预渲染不靠两个运行时互相调用,一个进程内闭环

覆盖需求:PRD-REQ-BUN-COMPAT、PRD-REQ-HEADLESS-BROWSER(蓝图 US-2)。

PRD-USERSTORY-SCRAPER 爬虫开发者:多页面采集且不被识别

作为 爬虫开发者，我想要 无头多页面并行采集,且站点端识别不出我是非常规客户端，以便 长爬任务上下文互不污染,采集规模上去后账号不被封

覆盖需求:PRD-REQ-HEADLESS-BROWSER、PRD-REQ-MULTIPAGE、PRD-REQ-STEALTH-NET、PRD-REQ-STEALTH-PAGE(蓝图 US-3)。

PRD-USERSTORY-RPA RPA 工程师:Playwright 直连且测不出自动化

作为 RPA 工程师，我想要 现有 Playwright 脚本直连内置运行时,页面端测不出自动化痕迹，以便 不改脚本迁移到可控运行时,业务流程自动化不被反自动化拦截

覆盖需求:PRD-REQ-CDP-CONNECT、PRD-REQ-STEALTH-AUTO、PRD-REQ-STEALTH-BEHAVIOR(蓝图 US-4)。

PRD-USERSTORY-SECURITY 安全研究员:网络监控与反检测研究

作为 安全研究员，我想要 监控与拦截页面网络流量,并在同一环境里验证指纹呈现与反检测对抗效果，以便 检测研究与验证在真实引擎里闭环,不靠拼凑多工具

覆盖需求:PRD-REQ-CDP-CONNECT、PRD-REQ-STEALTH-NET、PRD-REQ-STEALTH-PAGE(蓝图 US-5)。

PRD-USERSTORY-QA 自动化测试工程师:可复现的导航/DOM/截图

作为 自动化测试工程师，我想要 导航、DOM 断言、截图对比稳定可复现，以便 UI 回归不 flaky,测试结果可信

覆盖需求:PRD-REQ-HEADLESS-BROWSER、PRD-REQ-CDP-CONNECT(蓝图 US-6)。

PRD-USERSTORY-LIBAUTHOR 库作者:浏览器能力当库嵌入

作为 库作者，我想要 把浏览器能力当库嵌入自己的 Rust/JS 项目,也可接外部 Chrome,不绑定 CDP 协议细节，以便 产品能力成为我的依赖而非我的运行时,按需沙箱不可信代码

覆盖需求:PRD-REQ-UNIFIED-RUNTIME、PRD-REQ-MULTIPAGE、PRD-REQ-HIGHLEVEL-API、PRD-REQ-PERMISSION(蓝图 US-7)。
