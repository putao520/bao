03-SCENARIO — 业务场景/用户旅程

PRD-SCENARIO-RUN-TS-SCRIPT 首次运行 TS 脚本

触发:开发者在项目目录执行 bao run index.ts。期望:TypeScript 免预编译直接出结果,Node API 与浏览器式 API 共存。

  1. 执行 bao run index.ts,脚本内含 TS 类型注解
  2. 脚本 import 'node:fs' 读取本地文件并输出内容
  3. 同一脚本内浏览器式 API 与 Node API 共存可用
  4. 脚本抛异常时输出带 stack trace 的错误

PRD-SCENARIO-JEST-TEST 跑 Jest 风格测试

触发:开发者执行 bao test。期望:Jest 风格测试被发现并运行,结果可读。

  1. 执行 bao test
  2. 测试发现器扫描 *.test.* 文件
  3. describe/it/expect 风格用例被执行
  4. 输出通过/失败统计与失败详情

PRD-SCENARIO-BUILD-FRONTEND 打包前端产物

触发:开发者执行 bao build。期望:产物可直接运行,不依赖源码目录。

  1. 执行 bao build ./src/index.ts
  2. 打包器解析依赖图并产出可执行产物
  3. 产物在无源码目录环境可直接运行

PRD-SCENARIO-INSTALL-DEPS 安装依赖

触发:开发者执行 bao install。期望:依赖被解析下载就位,脚本可用。

  1. 执行 bao install
  2. 按 package.json 清单解析并下载依赖
  3. 依赖就位后 bao run 直接可用新装包

PRD-SCENARIO-HTTP-SERVER 同进程起 HTTP 服务与无头渲染

触发:全栈工程师用 Bun.serve 起服务并渲染页面。期望:服务与渲染同进程闭环。

  1. 脚本内 Bun.serve 监听端口返回路由响应
  2. 同进程创建页面并导航到本地服务地址
  3. 对页面无头渲染并截图验证输出
  4. 服务响应期间脚本主线程不被阻塞

PRD-SCENARIO-HEADLESS-SCREENSHOT 无头渲染截图

触发:爬虫/测试工程师把一段 HTML/CSS 渲染成图片。期望:排版正确,无窗口环境可用。

  1. 准备含 Flexbox/Grid/文字的 HTML
  2. 在无窗口环境创建页面加载该 HTML
  3. 渲染输出 PNG/JPEG/WebP 截图
  4. 核对布局与文字与浏览器呈现一致

PRD-SCENARIO-MULTIPAGE-CRAWL 多页面并行爬取

触发:爬虫任务同时打开多页采集。期望:页面间隔离,长爬不污染。

  1. 创建页面 A 登录目标站点
  2. 创建页面 B/C 并行采集不同列表页
  3. 切换回页面 A 时登录态保持,未被 B/C 污染
  4. 关闭空闲页面后资源被回收,长跑内存不增长

PRD-SCENARIO-PLAYWRIGHT-CONNECT Playwright 直连内置运行时

触发:RPA 工程师把现有 Playwright 脚本指向内置端点。期望:脚本零改动运行。

  1. 启动内置 CDP 端点 ws://127.0.0.1:9222
  2. Playwright 脚本 connectOverCDP 直连
  3. targets 列表可见内置页面
  4. 导航/截图/DOM 查询/输入注入用例全部通过
  5. 断开后页面与连接资源释放

PRD-SCENARIO-NETWORK-MONITOR-INTERCEPT 网络监控与拦截

触发:安全研究员/测试工程师监控页面网络。期望:请求响应可见且可拦截改写。

  1. 开启网络监控域事件
  2. 页面导航并发出若干请求
  3. 请求/响应(含 headers/body)在监听端可见
  4. 拦截规则改写请求/响应后页面行为随之变化

PRD-SCENARIO-STEALTH-FINGERPRINT-SITE 反指纹站点访问

触发:自动化访问带指纹检测的站点。期望:各探测面呈现目标真实浏览器(如 Firefox)特征。

  1. 以 stealth profile 配置目标浏览器(如 Firefox)
  2. 访问指纹检测站点(TLS/HTTP2/Canvas/WebGL/Audio/Navigator)
  3. 核对各探测面呈现值与目标浏览器一致
  4. 同 profile 重复访问结果一致,异 profile 相互区分
  5. 页面 JS 检测不到注入痕迹,主流检测站不识别

PRD-SCENARIO-BEHAVIOR-HUMANLIKE 拟人行为操作

触发:自动化脚本以拟人模式操作页面。期望:行为特征呈人类曲线。

  1. 启用拟人行为模式
  2. 鼠标移动到目标元素:轨迹为带偏移曲线
  3. 打字输入:节奏有起伏非均匀
  4. 滚动页面:带加减速
  5. 同 profile 重复执行行为序列可复现

PRD-SCENARIO-WORKER-FINGERPRINT-CONSISTENCY Worker 指纹一致性

触发:页面内 new Worker() 并行任务。期望:Worker 可用且指纹与主线程一致。

  1. 页面内 new Worker() 启动并行任务
  2. postMessage/结构化克隆传值正常
  3. terminate 后 Worker 停止
  4. Worker 内读取指纹呈现与主线程一致
  5. 反复创建销毁不崩溃不泄漏

PRD-SCENARIO-UNTRUSTED-SCRIPT-SANDBOX 不可信脚本权限沙箱

触发:运行不可信第三方脚本/页面。期望:未授权能力被明确拒绝。

  1. 以受限配置运行不可信脚本
  2. 脚本尝试访问文件系统被明确拒绝
  3. 脚本尝试未授权网络请求被明确拒绝
  4. 拒绝信息明确可诊断,非静默失败
  5. 页面与脚本同套权限逻辑生效

PRD-SCENARIO-TRUSTED-SCRIPT-FULL-POWER 可信脚本全权限

触发:运行自有可信脚本。期望:Node API 与 DOM 全权限同时可用,零额外负担。

  1. 以默认(无限制)配置运行可信脚本
  2. 脚本内 Node API 可用
  3. 同一脚本内 DOM 全权限可用
  4. 无双环境切换成本,能力默认在线
